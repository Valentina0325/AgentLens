## 修复真 bug：predictor.py 漏 `import json`，导致按 source 过滤的预测恒为 0
- 现象：`GET /api/traces/prediction?source=NEXUS_AI` 的 7 天历史全 0、predicted_cost=0；但不带 source 的预测正常（2026-10-01=0.005599 恰为 NEXUS_AI 的成本）。
- 根因：`predictor.py` 的 `_source_from_meta()` 调用 `json.loads(...)`，但文件顶部**未 import json** → 抛 `NameError` → 被 `except Exception` 静默吞掉 → 恒返回 `"unknown"` → 按 source 过滤时一条都匹配不上。
- 为何 summary 正常：`main.py` 有 `import json`，只有 predictor.py 漏了。
- 修复：`backend/predictor.py` 顶部补 `import json`（1 行）。重启后验证：`?source=NEXUS_AI` 的 2026-10-01 正确显示 0.005599，predicted_cost=0.0008。
- 教训：`except Exception` 吞异常会掩盖 NameError 这类低级错误；来源筛选相关的解析函数应单独自测。
- 未跑 pytest（避免污染已重灌的 58 条演示数据），如需回归请自行 `pytest`。
